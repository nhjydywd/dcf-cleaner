# DCF Cleaner

[English](README.md) | [中文](README.zh.md)

DCF Cleaner is a file cleanup app (Flutter Desktop).

Version: 1.0.0 (macOS)

![DCF Cleaner Screenshot](images/main.png)

## Features

1. Automatically scans the selected folder recursively and presents a summarized view.
2. Provides AI suggestions on whether a file/folder can be deleted.
